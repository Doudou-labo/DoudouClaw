**Ce qui s'est passé :** J'ai tenté `npm install -g openclaw@latest` avec le gateway en cours d'exécution → erreur `ENOTEMPTY` (npm ne pouvait pas renommer le dossier occupé par le process) → binaire `/usr/bin/openclaw` cassé → Alexandre a dû tout réparer manuellement depuis son téléphone via SSH (arrêt gateway, suppression résidus npm, cache clean, réinstall --force).

**Leçon :** Pour mettre à jour OpenClaw :
1. **Prévenir Alexandre** que le gateway va être coupé
2. Arrêter le gateway : `systemctl --user stop openclaw-gateway`
3. Attendre que le process soit mort : `pgrep -f openclaw`
4. Installer : `npm install -g openclaw@latest --force`
5. Redémarrer : `systemctl --user start openclaw-gateway`
6. Vérifier : `openclaw --version`

**Ne JAMAIS** lancer `npm install -g openclaw` avec le gateway actif.

**Config appliquée post-update :** `agents.defaults.heartbeat.directPolicy = block` (breaking change v2026.2.25 qui repasse à `allow` par défaut).
