# Journal du 2026-03-11

## Projet : pneu-tracker

### Décision
Création d'une application web de suivi de sorties de pneus pour Alexandre (usage Euromaster).

### Stack retenue
- Next.js 15 (App Router) + TypeScript + Tailwind CSS
- SQLite via `better-sqlite3` (stockage local, fichier `data/pneus.db`)
- Port prod : 3002
- Service systemd : `pneu-tracker.service`
- Caddy reverse proxy : `https://pneus.doudougen.xyz`
- Auth Basic : DoudouClaw / mot de passe habituel

### Fonctionnalités livrées
1. Formulaire : Date (date picker), Immatriculation (auto-uppercase), Code SAP (optionnel), Quantité, Description
2. Historique : liste triée par date décroissante, compteur, bouton supprimer
3. Export CSV : bouton ⬇️ Export CSV, fichier nommé `sorties-pneus-YYYY-MM-DD.csv`, UTF-8 BOM (compatible Excel)
4. Recherche temps réel : filtre sur date, immat, code SAP, description — compteur `X / total` + bouton ✕

### Chemins clés
- App : `/root/projects/pneu-tracker/`
- DB : `/root/projects/pneu-tracker/data/pneus.db`
- Service : `/etc/systemd/system/pneu-tracker.service`
- Caddy : `/etc/caddy/Caddyfile`

### Incident technique
- Claude Code (`--permission-mode bypassPermissions`) bloqué en root → app construite manuellement par l'agent principal.

### Statut
✅ Live et fonctionnel sur https://pneus.doudougen.xyz
