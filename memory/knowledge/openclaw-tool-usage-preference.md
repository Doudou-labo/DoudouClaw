# Connaissance — Préférence usage outils

## Préférence validée
Alexandre veut que l’agent exploite de façon proactive les outils pertinents disponibles, sans rester bloqué sur un petit sous-ensemble par habitude.

## Garde-fou
Utiliser le bon outil dès qu’il apporte de la valeur, sans enchaîner des appels inutiles juste pour cocher une case.
