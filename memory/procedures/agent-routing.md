# Procédure — Routage agents

## Règle simple
- 1 domaine / tâche courte → `main`
- 2 domaines ou plus → `spec-orchestrator`
- action sensible → validation sécurité

## But
Choisir le bon agent sans friction et garder une synthèse unique côté utilisateur.
