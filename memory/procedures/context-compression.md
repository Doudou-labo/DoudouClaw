# Procédure — Compression de contexte

## Principe
Quand le contexte devient trop lourd, compresser proprement au lieu de perdre le fil.

## Règle
- préserver décisions, open loops, prochaine action
- réinjecter l’essentiel dans les fichiers mémoire canoniques
- garder la continuité exploitable après compaction
