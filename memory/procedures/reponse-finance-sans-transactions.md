# Procédure — Réponse finance sans transactions

## Règle
Quand Alexandre demande l’état ou le détail de ses comptes :
- répondre avec les soldes
- séparer Revolut / portefeuille actions / PERCO Natixis
- ne pas donner de total combiné sauf demande explicite
- ne pas lister les transactions sauf demande explicite
