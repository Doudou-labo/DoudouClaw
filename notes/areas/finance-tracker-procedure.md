# Procédure Finance-Tracker

Quand Alexandre parle d’argent (dépenses, abonnements, paiements, abonnements, revenus, objectifs financiers…) :

1. **Utiliser systématiquement le skill `finance-tracker`**.
   - Exécuter les commandes appropriées (`finance add`, `finance recurring`, `finance report`, `finance insights`, etc.) pour répondre de manière précise.
   - Si besoin d’un résumé rapide, préfèrer `finance summary` ou `finance report week`.
2. **Documenter chaque interaction** avec un mini-récap : montant, description, commande utilisée, résultat.
3. **Proposer une action** claire ensuite (rappel, vérification, objectif…) en se basant sur les données du skill.
4. **Mettre à jour `git`** : ajouter ou modifier une note à chaque fois qu’une nouvelle règle de gestion financière est décidée.

*Référence du skill :* `skills/finance-tracker/SKILL.md`. Le dossier contient la documentation complète et les commandes.
