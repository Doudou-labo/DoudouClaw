## 📝 Comment ça marche

### Pour ajouter un item
Envoie-moi n'importe quel bazar mental (vocal, texte, Discord, Telegram). Je :
1. Détecte le pattern
2. Pose les questions de challenge
3. Classe dans la bonne case
4. Mets à jour ce fichier

### Pour déplacer un item
Dis-moi : "Déplace [item] de [case A] vers [case B]" ou "[Item] est fait"

- Ce fichier : `notes/areas/tdah-matrix-dashboard.md`
