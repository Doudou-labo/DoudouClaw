# Intelligence émotionnelle (IE)

## Définition
Capacité à reconnaître, comprendre et réguler ses émotions (et à naviguer celles des autres) pour mieux agir.

## Pourquoi c’est utile
- Réduire les réactions “à chaud” (conflits, stress, décisions impulsives)
- Améliorer la communication et la confiance au travail
- Mieux manager (écoute, feedback, motivation) — utile pour évoluer vers RCS

## Comment ça fonctionne
L’IE se travaille via 3 micro-étapes répétées :
1) **Identifier** : « Qu’est-ce que je ressens, exactement ? »
2) **Nommer** : colère, frustration, peur, fatigue, honte, etc.
3) **Choisir** : « Quelle action me sert *vraiment* maintenant ? »

Exemple (situation Euromaster) :
- Un client s’énerve au téléphone.
- Réflexe : répondre sec.
- IE :
  - Identifier : tension + agacement
  - Nommer : frustration (car je me sens attaqué)
  - Choisir : baisser le ton, reformuler, proposer une solution + délai

```
Mini-script IE (20 secondes)
- Je ressens : ______
- Parce que : ______
- J’ai besoin de : ______
- Je choisis : ______
```

## Insight clé
L’émotion est une **info**, pas un ordre. La différence se fait entre “je ressens” et “je fais”.
