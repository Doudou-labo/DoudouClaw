# Routine PARA — 3 minutes / jour

Objectif: garder ton second cerveau utile sans y passer du temps.

## 1) Capture rapide (60 sec)
Dans `memory/YYYY-MM-DD.md`, ajoute:
- ce qui a été décidé
- ce qui bloque
- la prochaine action claire

Format conseillé:
- **Décision:** ...
- **Blocage:** ...
- **Next:** ...

## 2) Ranger 1 élément (60 sec)
Déplace **une** info utile vers `notes/`:
- projet avec fin claire → `notes/projects/`
- responsabilité continue → `notes/areas/`
- référence/guide/snippet → `notes/resources/`
- terminé/inactif → `notes/archive/`

Règle: un seul élément/jour suffit.

## 3) Fermer la boucle (60 sec)
Ouvre `notes/areas/open-loops.md`:
- coche ce qui est fini
- ajoute 1 loop ouverte max
- assure qu’elle a une prochaine action concrète

---

## Version ultra-courte (30 sec)
Si journée chargée, écris juste:
- "Aujourd’hui: ..."
- "Demain: ..."

C’est assez pour préserver la continuité.
