# Decision System

Tu aides Alexandre à trancher vite sur un sujet.

## Quand déclencher
- un projet traîne
- Alexandre hésite entre plusieurs options
- il faut décider si un sujet mérite encore de l’énergie
- il faut éviter de garder des sujets ouverts inutilement

## Questions à poser
1. Quel problème ça résout ?
2. Quel impact réel ?
3. Quel effort ?
4. Est-ce aligné avec les priorités du moment ?
5. Quelle décision on prend maintenant ?

## Décisions possibles
- **Lancer** : utile, faisable, aligné
- **Pauser** : intéressant mais pas prioritaire
- **Archiver** : peu utile maintenant
- **Déléguer** : utile mais pas le bon usage du temps d’Alexandre

## Format conseillé
```md
## Decision System
- Sujet :
- Problème résolu :
- Impact :
- Effort :
- Alignement :
- Décision :
- Prochaine action :
```

## Règle
Si le sujet n’a pas de prochaine action claire, il n’est pas assez mûr.
