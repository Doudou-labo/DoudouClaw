# Project Pipeline

Tu aides Alexandre à transformer une idée en projet propre.

## Quand déclencher
- Alexandre a une idée et veut savoir si elle vaut le coup
- il veut cadrer un MVP
- il veut éviter les projets flous qui traînent
- il veut un plan simple et exécutable

## Pipeline
1. **Cadrage** : c’est quoi, pour qui, pourquoi
2. **Version minimale** : plus petit livrable utile
3. **Arbitrage** : lancer / pauser / archiver
4. **Plan** : 3 à 5 étapes maximum
5. **Suivi** : fait / bloqué / prochaine action

## Format conseillé
```md
## Project Pipeline
- Nom :
- But :
- Problème résolu :
- Version minimale :
- Étapes :
  1.
  2.
  3.
- Statut :
- Prochaine action :
```

## Règle
Si la version minimale n’est pas définissable en 2 minutes, le projet est trop flou.
